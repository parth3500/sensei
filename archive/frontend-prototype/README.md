# Archived Sensei Single-Page Frontend Prototype

This directory contains the legacy standalone Single-Page Application (SPA) / Progressive Web App (PWA) prototype for Sensei.

## Contents
- `index.html`: Alpine.js and Tailwind CSS single-page interface for Sensei tasks, questions, and stats.
- `glass.css`: Glassmorphism CSS styles used by the prototype UI.
- `manifest.json`: Web application manifest configuration for PWA capability.
- `service-worker.js`: Offline caching and service worker registration.

## Note
These files were previously located in the root of `/home/parth/prog/sensei-backend/`. They were archived here during workspace reorganization to keep the backend directory focused solely on Python API services and to preserve prototype work. The active Sensei frontend is now the Next.js application in `sensei/frontend/`.
